MONVATTI MARKETPLACE — TESTE RÁPIDO
====================================

São duas partes: o SERVIDOR (uma janela de comando que fica aberta) e a
EXTENSÃO (no Chrome). Siga na ordem.


PARTE 1 — LIGAR O SERVIDOR (uma vez)
------------------------------------
Precisa de Python 3.11+ instalado (python.org; na instalação marque
"Add Python to PATH").

Abra o Prompt de Comando dentro desta pasta e rode, uma linha por vez:

    python -m venv .venv
    .venv\Scripts\activate
    pip install -r requirements.txt
    python -m backend.seed
    uvicorn backend.main:app --port 8000

A última linha deixa a janela "parada" escrevendo logs — é assim mesmo,
deixe aberta. O servidor fica em  http://localhost:8000


PARTE 2 — INSTALAR A EXTENSÃO NO CHROME
---------------------------------------
1. Abra  chrome://extensions
2. Ligue o "Modo do desenvolvedor" (canto superior direito).
3. Clique em "Carregar sem compactação" e escolha a pasta  extensao
4. Clique no ícone da Monvatti na barra do Chrome.
5. No endereço do servidor digite:  http://localhost:8000
6. No e-mail digite:  alexmonvatti@gmail.com
7. Clique em Entrar e aceite a permissão.
